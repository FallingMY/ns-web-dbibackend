    ❓ 帮助 / Help

    无法连接设备的排查指南 / Troubleshooting guide

    Windows：修改 USB 驱动

    1. 下载：从 zadig.akeo.ie 下载 Zadig 驱动安装工具。

    2. 安装：Switch 上启动 DBI「后端」模式并连接电脑 → 打开 Zadig → Options → List All Devices → 选择 Switch 设备（VID 057E / PID 3000）→ 目标驱动选 WinUSB → 点击 Install Driver → 重新插拔 USB。

    3. 修改：如果之前装过 libusbK 等其他驱动导致设备无法识别，重复第 2 步把驱动改为 WinUSB 即可（无需先卸载旧驱动）。

    4. 还原：安装 WinUSB 后 DBI 的 MTP 模式将不可用。恢复 MTP：设备管理器 → 右键 Switch 设备 → 更新驱动程序 → 浏览我的电脑 → 让我从列表中选取 → 选择 MTP USB Device → 安装。如需还原为 libusbK（供旧版 dbibackend 使用），用 Zadig 重复第 2 步并选择 libusbK 即可。

    常见问题 / FAQ

    选择设备时看不到 Switch：Windows 下通常是驱动问题，见上方教程；macOS 下检查 USB 线是否支持数据传输、更换接口，并确认 DBI 已进入「后端」模式。

    提示"不支持 WebUSB"：页面必须通过 HTTPS 或 localhost 访问，直接打开本地文件（file://）或通过非 localhost 的 IP 访问无法使用 WebUSB。

    传输中断后无法重新连接：USB 传输超时后连接无法恢复，工具会自动断开并提示重新连接；如仍失败请刷新页面后重试。

    资源管理器里看不到 MTP 设备：设备的驱动被替换过（如安装了 WinUSB / libusbK），按上方「还原」步骤恢复 MTP 驱动。

    提示"未找到 Bulk 端点"：确认 Switch 上 DBI 处于「后端」模式且驱动正确，重新插拔 USB 后重试。
